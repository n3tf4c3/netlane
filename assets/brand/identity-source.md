# NetLane - Pacote de Identidade Visual

Este pacote contém os arquivos vetoriais (SVG) prontos para uso no seu projeto:

## 📁 Arquivos inclusos:
- `logo-light.svg`: Logotipo completo (ícone + tipografia) otimizado para fundos claros e brancos.
- `logo-dark.svg`: Logotipo completo otimizado para fundos escuros / modo noturno / terminal.
- `icon-app.svg`: Ícone quadrado arredondado com fundo, ideal para Favicon, app launcher e dock.
- `icon-transparent.svg`: Apenas o símbolo do cabo NL em vetor com fundo transparente para botões, navbar ou splash screens.

## 🎨 Cores principais:
- Teal / Ciano Primário: `#14b8a6`
- Gradiente Escuro: `#0d9488`
- Azul Destaque: `#38bdf8`
- Dark BG: `#090d16` / `#0d282a`
